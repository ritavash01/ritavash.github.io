# Ritavash Debnath — personal website

Static website for GitHub Pages. No build step or dependencies are needed.

## Publish

1. Create or use the repository `ritavash01/ritavash01.github.io`.
2. Upload the contents of this folder to the root of its `main` branch.
3. Under **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**.
4. Once deployment succeeds, the site will be at https://ritavash01.github.io/.

## Edit

- `index.html`: page content and links
- `style.css`: appearance and responsive layout
- `script.js`: research tabs and Spotify player
- `assets/Ritavash-Debnath-CV.pdf`: downloadable CV
- `assets/ritavash-portrait.png`: portrait

The repository contains the intended website content, including the CV and photograph.
